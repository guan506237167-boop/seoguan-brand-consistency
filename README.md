**第一次使用：先看[详细操作教程](USAGE.md)**（材料模板、可复制指令、样例和结果检查）。

## 输入与输出

输入：目标主体及官网；待比较的简介、页面文本或来源链接，附时间和平台。

输出：brand-consistency.md：实体候选表、冲突清单、待确认项、逐平台建议文案。

## 工作步骤

1. 建立来源×字段矩阵；保留精确名称、域名和公司全称。
2. 先核对主体再核对表述：主体相同但简称不同属于别名候选，主体或域名不一致须单列。
3. 区分事实矛盾、历史变更、缺失、文案差异；只有证据明确时才能判定历史变更。
4. 给每处问题指出原句、影响和建议修订，未定事实用待确认，不能自动覆盖公开页面。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-brand-consistency`。支持 `$技能名` 的宿主可使用下方示例。

依赖：不要求 Python、GEO 后台账号或付费 API。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。
